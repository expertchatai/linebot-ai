# คู่มือ Admin

พนักงานควบคุมระบบผ่าน **LINE OA ผู้ดูแล** (แชท 1:1 หรือในกลุ่ม) ส่วน Dashboard ใช้ดูและตรวจสอบข้อมูลเท่านั้น

## สิทธิ์

| | Super Admin | Admin |
|---|---|---|
| เพิ่ม/ยกเลิก Admin | ✅ | – |
| เปลี่ยน TEST ↔ LIVE MODE | ✅ | – |
| อนุมัติข้อมูล | ✅ | ✅ |
| เปิด/ปิด AI, ปิดหัวข้อ, เปิด AI รายแชท | ✅ | ✅ |
| รับเรื่อง / ปิดเรื่อง | ✅ | ✅ |

- Super Admin กำหนดผ่าน env `SUPER_ADMIN_LINE_USER_IDS`
- ขอสิทธิ์ Admin: พิมพ์ `MYID` ใน OA ผู้ดูแล แล้วส่ง ID ให้ Super Admin เพิ่มด้วย `ADMIN ADD <userId> <ชื่อ>`

## คำสั่ง

พิมพ์ `HELP` เพื่อดูคำสั่งทั้งหมด

| คำสั่ง | ความหมาย |
|---|---|
| `STATUS` | ดูโหมด, AI แต่ละช่องทาง, สถานะ Sheets, เรื่องที่รอดำเนินการ |
| `ASK <คำถาม>` | ทดลองถาม AI (ไม่ส่งถึงลูกค้า) แสดงคำตอบ, ข้อมูลที่อ้างอิง และเหตุผล |
| `AI LINE OFF` / `AI MESSENGER ON` | เปิด/ปิด AI ทั้งช่องทาง |
| `TOPIC OFF brand Rolex` | ปิดการตอบเรื่องแบรนด์ Rolex โดยคำถามเรื่องนี้จะส่งต่อเจ้าหน้าที่แทน |
| `TOPIC OFF service ติดฟิล์ม` / `TOPIC OFF model Daytona` | ปิดหัวข้อตามบริการหรือรุ่น |
| `TOPIC ON ...` / `TOPICS` | เปิดหัวข้อกลับ / ดูหัวข้อที่ปิดอยู่ |
| `OFFAI` | ดูรายการแชทที่ AI หยุดอยู่ พร้อมปุ่ม "เปิด AI แชทนี้" |
| `OFFAI C1023` / `ONAI C1023` | หยุด / เปิด AI เฉพาะแชทนั้น |
| `HANDOFFS` | เรื่องที่รอเจ้าหน้าที่ |
| `PENDING` | ชุดข้อมูลที่รออนุมัติ |
| `SYNC` | ตรวจ Google Sheets ทันที |
| `FIND <คำ>` | ค้นข้อมูล Approved และดูรหัส (K12) |
| `ADD หมวด \| คำถาม \| คำตอบ` | เพิ่มข้อมูลผ่าน LINE (ต้องอนุมัติก่อนใช้งาน) |
| `EDIT K12 \| คำตอบใหม่` / `DEL K12` | แก้/ลบข้อมูลที่เพิ่มผ่าน LINE |
| `TESTER ADD <id>` / `TESTERS` | จัดการบัญชีทดสอบ (ลูกค้าพิมพ์ `#MYID` ใน OA ลูกค้าเพื่อดู id ของตัวเอง) |
| `MODE LIVE` / `MODE TEST` | (Super Admin) เปลี่ยนโหมด |

**ทุกคำสั่งที่กระทบลูกค้า** ระบบจะแสดงผลกระทบก่อน แล้วรอให้กด **ยืนยัน** ภายใน 10 นาที

> ข้อมูลที่มาจาก Google Sheets ต้องแก้ใน Sheet เท่านั้น เพราะระบบไม่เขียนทับ Sheet เดิม

## การอนุมัติข้อมูล

1. เมื่อมีคนแก้ Google Sheets ระบบจะรอจนไม่มีการแก้เพิ่มครบ 1 นาที แล้วรวมการเปลี่ยนแปลงเป็นชุดเดียว
2. กลุ่ม Admin จะได้รับข้อความพร้อมปุ่ม **ดูทีละรายการ / อนุมัติทั้งชุด / ปฏิเสธทั้งชุด**
3. ปุ่มดูทีละรายการจะแสดงข้อมูลเดิมเทียบกับข้อมูลใหม่ และมีปุ่ม **อนุมัติ / ปฏิเสธ** แยกแต่ละรายการ
4. ข้อมูลที่อนุมัติแล้วจะถูกใช้ทันที ส่วนข้อมูลที่รออนุมัติหรือถูกปฏิเสธ AI จะไม่นำไปใช้
5. ถ้ามีคนกดซ้ำหรือมีคนกดไปก่อนแล้ว ระบบจะแจ้งว่าใครเป็นผู้ดำเนินการ ไม่มีการอนุมัติซ้ำ
6. รายการที่รออนุมัติจะค้างอยู่จนกว่าจะมีคนตัดสินใจ ระบบไม่แจ้งเตือนซ้ำ ส่วนเนื้อหาที่ถูกปฏิเสธจะไม่ถูกเสนอซ้ำจนกว่าจะมีการแก้ไขใหม่

## เมื่อ Google Sheets ขัดข้อง

- AI ยังตอบลูกค้าได้ตามปกติจากข้อมูล Approved ที่สำรองไว้ใน Supabase และกลุ่ม Admin จะได้รับแจ้งเตือน
- เมื่อ Sheets กลับมา ถ้าข้อมูลตรงกันระบบจะกลับมาทำงานเอง
- ถ้าข้อมูลไม่ตรงกัน ระบบจะส่งชุด **"ต้องเลือกข้อมูลที่ถูกต้อง"** ให้เลือกทีละรายการ
  - **ใช้ข้อมูล Sheet** = รับข้อมูลใหม่จาก Sheet
  - **ใช้ข้อมูลสำรอง** = คงข้อมูลเดิม (จากนั้นควรแก้ Sheet ให้ตรงด้วยตัวเอง)
- ระหว่างนั้นการขออนุมัติตามปกติจะหยุดไว้ก่อน จนกว่าจะเลือกครบทุกรายการ

## การส่งต่อเจ้าหน้าที่

AI จะหยุดตอบแชทนั้นและแจ้งกลุ่ม Admin เมื่อเกิดกรณีต่อไปนี้
- ลูกค้าถามสถานะงานซ่อม (ส่งต่อทันที)
- มีข้อร้องเรียน หรือลูกค้าขอคุยกับเจ้าหน้าที่
- เจอคำถามที่ไม่มีในข้อมูล หรือ AI ไม่แน่ใจ (รวมถึงคำตอบที่มีราคาซึ่งไม่ตรงกับข้อมูล)
- ลูกค้าส่งวิดีโอหรือไฟล์
- คำถามอยู่ในหัวข้อที่ปิดไว้

ข้อความแจ้งเตือนจะมีรหัสแชท, สรุปประเด็น และร่างคำตอบ เจ้าหน้าที่ต้องตอบลูกค้าเองผ่าน LINE OA Manager หรือ Meta Business Suite
**ระบบไม่ส่งร่างคำตอบให้ลูกค้าอัตโนมัติ**

- กด **รับเรื่องแล้ว** เพื่อหยุดการเตือนซ้ำ ระบบจะบันทึกชื่อผู้รับเรื่องและเวลา
- ถ้ายังไม่มีใครรับเรื่อง ระบบจะเตือนซ้ำทุก 15 นาที เฉพาะช่วง 08:30–20:00 น.
- เมื่อดูแลเสร็จ ให้กด **ปิดเรื่อง** และถ้าต้องการให้ AI ตอบแชทนี้ต่อ ให้กด **เปิด AI แชทนี้** หรือพิมพ์ `ONAI <รหัส>`

คำขอนัดหมายหรือคำขอให้ติดต่อกลับ จะถูกส่งเข้ากลุ่มพร้อมชื่อ, เบอร์, บริการ, สาขา และวันเวลาที่สะดวก
AI จะไม่ยืนยันนัดเอง เจ้าหน้าที่ต้องติดต่อกลับเพื่อยืนยัน
